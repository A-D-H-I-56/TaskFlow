About TaskFlow

TaskFlow is a lightweight, responsive containerized task-management application built to demonstrate containerization and modern automated release engineering. Serving static files with a Nginx-alpine web server, it showcases full automation through CI/CD pipelines via GitHub Actions and Render.

Usage Guide

Adding Tasks

Navigate to the 'Add Task' page, fill in the form details (title, description, date, and priority level), and click Save.

Filtering Tasks

View the task board under 'Task List' and toggle filter buttons (All, Pending, Completed) to filter tasks.

Managing Status

Click 'View' on any task in the list to inspect details. Mark it as completed or permanently delete it.
